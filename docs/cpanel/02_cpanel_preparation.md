# 准备cPanel环境

在开始部署Django项目之前，需要在cPanel中进行一些基本设置。本文档将指导您完成cPanel环境的准备工作，包括创建数据库、配置Python应用程序设置等。

## 登录cPanel控制面板

1. 使用主机提供商提供的URL访问cPanel控制面板（通常是 `https://yourdomain.com:2083` 或 `https://server-ip:2083`）
2. 输入您的cPanel用户名和密码
3. 登录后，您将看到cPanel的主界面

## 创建MySQL数据库和用户

### 创建数据库

1. 在cPanel主界面中，找到并点击**"MySQL数据库"**或**"MySQL数据库向导"**（在"数据库"部分）
2. 在"创建新数据库"部分，输入数据库名称（例如 `multi_tenant_db`）
   - 注意：cPanel会自动在数据库名称前添加您的cPanel用户名作为前缀，例如 `username_multi_tenant_db`
3. 点击**"创建数据库"**按钮
4. 记下完整的数据库名称（包括前缀）

### 创建数据库用户

1. 在同一页面或返回到MySQL数据库页面
2. 找到"添加新用户"部分
3. 输入用户名（例如 `django_user`）
   - 同样，cPanel会自动添加前缀
4. 输入并确认密码
   - 建议使用强密码生成器创建安全密码
   - 记下此密码，后续配置需要使用
5. 点击**"创建用户"**按钮

### 分配用户权限

1. 在MySQL数据库页面，找到"添加用户到数据库"部分
2. 从下拉菜单中选择刚创建的用户和数据库
3. 点击**"添加"**按钮
4. 在权限页面，选择**"所有权限"**（或根据安全需求选择特定权限）
5. 点击**"确定"**保存设置

## 检查Python支持

确认您的cPanel账户支持Python应用程序：

1. 在cPanel主界面，搜索**"Setup Python App"**或**"Python"**
2. 如果找不到此选项，请联系您的主机提供商，确认是否支持Python应用程序
3. 检查可用的Python版本，确保支持Python 3.9+（推荐3.12或更高版本）

## 配置SSH访问（可选但推荐）

如果您的cPanel账户支持SSH访问，建议配置SSH以便更方便地管理项目：

1. 在cPanel主界面，找到并点击**"SSH访问"**或**"SSH/Shell访问"**
2. 如果需要，生成或上传SSH密钥
3. 确保SSH访问已启用

## 配置文件目录结构

在cPanel中，了解文件目录结构非常重要：

1. 公共可访问目录通常是 `public_html`
2. 对于安全考虑，建议将Django项目放在公共目录之外，只有静态文件和媒体文件放在公共目录中

### 推荐的目录结构

```
/home/username/                  # 用户根目录
├── public_html/                 # 公共可访问目录
│   ├── static/                  # 静态文件（符号链接或实际文件）
│   └── media/                   # 媒体文件（符号链接或实际文件）
├── lipeaks_backend/             # Django项目目录（非公开）
│   ├── core/
│   ├── users/
│   ├── ...
│   ├── manage.py
│   └── passenger_wsgi.py        # Passenger WSGI入口文件
└── logs/                        # 日志目录（可选）
```

## 创建必要的目录

使用cPanel的文件管理器或SSH创建所需目录：

### 使用文件管理器

1. 在cPanel主界面，点击**"文件管理器"**
2. 导航到您的主目录
3. 点击**"新建文件夹"**按钮，创建 `lipeaks_backend` 目录（如果计划通过Git克隆，可以跳过此步骤）
4. 如果需要，创建 `logs` 目录

### 使用SSH（如果可用）

```bash
mkdir -p ~/lipeaks_backend
mkdir -p ~/logs
```

## 检查和设置文件权限

确保目录具有适当的权限：

1. 在文件管理器中，右键点击目录，选择**"更改权限"**
2. 设置以下权限：
   - 项目目录：`750`（用户可读写执行，组可读执行，其他无权限）
   - 公共目录：`755`（用户可读写执行，组和其他可读执行）
   - 日志目录：`700`（仅用户可读写执行）

## 检查PHP版本和设置

虽然我们部署的是Django项目，但了解服务器的PHP设置也很有用，因为cPanel的许多功能依赖于PHP：

1. 在cPanel主界面，找到并点击**"PHP版本"**或**"MultiPHP Manager"**
2. 记下当前的PHP版本和设置
3. 通常不需要更改默认设置，除非您计划同时运行PHP应用程序

## 检查服务器限制

了解您的cPanel账户的资源限制：

1. 在cPanel主界面，找到并点击**"资源使用"**
2. 检查以下限制：
   - CPU使用限制
   - 内存使用限制
   - 进程限制
   - 入站和出站流量限制
   - 数据库大小限制
   - 存储空间限制

这些限制将影响您的Django应用程序性能和配置选择。
