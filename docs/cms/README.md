# CMS系统菜单配置指南

## 概述

本文档说明如何为CMS系统配置菜单结构。CMS系统菜单基于项目的菜单管理系统构建，提供完整的内容管理功能导航。

## 菜单结构

CMS系统的菜单结构如下：

1. **CMS管理** (顶级菜单，已存在)
   - **文章管理**
     - 创建文章
     - 文章列表
     - 文章归档
   - **评论管理**
     - 待审核评论
     - 已批准评论
     - 垃圾评论
   - **分类管理**
   - **标签管理**
     - 标签组
     - 标签列表
   - **内容统计**
     - 文章统计
     - 互动统计

## 菜单数据

菜单数据存储在 `docs/cms/cms_menus.json` 文件中，遵循Django fixture格式。此文件包含所有CMS系统所需的菜单项，包括名称、路径、图标等信息。

## 如何加载菜单

项目提供了一个自定义管理命令来加载CMS菜单数据：

```bash
python manage.py load_cms_menus
```

执行此命令将：
1. 读取 `docs/cms/cms_menus.json` 文件中的菜单数据
2. 将菜单数据加载到数据库中
3. 自动处理菜单之间的父子关系
4. 跳过父菜单不存在的菜单项

## 注意事项

1. 确保在加载CMS菜单前，已存在ID为4的"CMS管理"顶级菜单
2. 菜单加载是幂等的，可以多次执行而不会产生重复数据
3. 执行命令时会自动验证父子关系，确保数据完整性
4. 如需修改菜单结构，可以编辑`cms_menus.json`文件后重新执行加载命令

## 前端路由集成

前端应用需要通过API获取菜单数据并构建路由：

1. 使用 `/api/v1/menus/tree/` 接口获取树形结构的菜单数据
2. 根据返回的菜单数据动态生成路由配置
3. 在前端应用中实现对应的组件

## 自定义菜单

如需添加或修改CMS菜单，建议按照以下步骤操作：

1. 编辑 `docs/cms/cms_menus.json` 文件
2. 确保每个菜单项都有唯一的`pk`值
3. 设置正确的`parent`字段值，建立父子关系
4. 执行`python manage.py load_cms_menus`更新菜单数据
