# RBAC API设计

本文档定义了RBAC权限控制系统的API接口设计。这些接口将支持系统中的两种用户模型（User和Member）管理权限和角色。

## 1. API概述

RBAC API主要包括以下几个部分：

- 权限管理API
- 角色管理API
- 用户角色管理API
- 权限验证API

所有接口都遵循RESTful设计原则，支持标准的HTTP方法，并返回统一格式的JSON响应。

## 2. 统一响应格式

所有API响应都遵循以下统一格式：

**成功响应**:
```
{
  "code": 200,
  "message": "success",
  "data": {
    // 响应数据
  }
}
```

**错误响应**:
```
{
  "code": 400,
  "message": "错误描述",
  "errors": {
    // 详细错误信息
  }
}
```

### 2.1 状态码设计

| 状态码 | 描述 |
|-------|------|
| 200 | 请求成功 |
| 201 | 资源创建成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 3. 权限管理API

### 3.1 API端点设计

| 方法 | 路径 | 描述 |
|-----|------|------|
| GET | /api/rbac/permissions/ | 获取权限列表 |
| GET | /api/rbac/permissions/{id}/ | 获取权限详情 |
| POST | /api/rbac/permissions/ | 创建权限 |
| PUT | /api/rbac/permissions/{id}/ | 更新权限 |
| DELETE | /api/rbac/permissions/{id}/ | 删除权限 |
| GET | /api/rbac/permissions/categories/ | 获取权限类别 |
| GET | /api/rbac/permissions/check/ | 权限检查 |

### 3.2 数据结构

**权限对象**:
```
{
  "id": "权限ID",
  "code": "权限代码",
  "name": "权限名称",
  "description": "权限描述",
  "category": "权限类别",
  "is_system": "是否系统权限"
}
```

### 3.3 请求流程图

```
+------------------+     +------------------+     +------------------+
|  客户端          |---->|  权限列表请求    |---->|  权限过滤处理   |
+------------------+     +------------------+     +------------------+
        ^                                                 |
        |                                                 v
+------------------+     +------------------+     +------------------+
|  展示权限列表    |<----|  响应处理        |<----|  查询数据库     |
+------------------+     +------------------+     +------------------+
```

## 9. API版本控制

API版本控制通过以下方式实现：

1. URI路径版本：`/api/v1/rbac/permissions/`
2. 请求头版本：`Accept: application/vnd.api.v1+json`

### 9.1 版本管理策略

- 主版本号：不兼容的API变更
- 次版本号：向后兼容的功能性新增
- 修订号：向后兼容的问题修正

## 10. API安全设计

### 10.1 安全架构图

```
+------------------+     +------------------+     +------------------+
|  API请求         |---->|  认证中间件      |---->|  授权中间件     |
+------------------+     +------------------+     +------------------+
                                                          |
                                                          v
+------------------+     +------------------+     +------------------+
|  速率限制        |<----|  请求验证        |<----|  权限检查       |
+------------------+     +------------------+     +------------------+
        |
        v
+------------------+     +------------------+
|  API控制器       |---->|  审计日志        |
+------------------+     +------------------+
```

### 10.2 安全措施

1. **认证**：JWT令牌验证
2. **授权**：RBAC权限控制
3. **速率限制**：防止DoS攻击
4. **输入验证**：防止注入攻击
5. **审计日志**：记录关键操作
