## ✅ 完整修复方案

### 修复1: 统一权限检查逻辑 ✅

**文件**: `feedbacks/permissions.py`

**添加可靠的辅助函数**:
```python
def is_tenant_admin(user):
    """判断是否为租户管理员"""
    if not user or not user.is_authenticated:
        return False
    
    if not hasattr(user, 'is_admin'):
        return False
    
    return (
        user.is_admin and 
        not getattr(user, 'is_super_admin', False)
    )
```

**优势**:
- 直接检查字段值，不依赖@property  
- 避免JWT Token序列化问题
- 跨模块调用更可靠

### 修复2: User模型is_staff设置 ✅

**文件**: `users/models.py`

**修改**: 所有管理员都设置 `is_staff=True`
```python
# 所有管理员用户都设置为staff
self.is_staff = True
```

**结果**:
- 超级管理员: `is_staff=True, is_superuser=True`
- 租户管理员: `is_staff=True, is_superuser=False`

### 修复3: 数据修复 - 软件分类租户归属 ✅

**问题**: 软件分类记录 `tenant_id = NULL`

**解决**: 自动分配给用户的租户
```python
# 修复前
SoftwareCategory(id=1, name="app", tenant_id=None)

# 修复后  
SoftwareCategory(id=1, name="app", tenant_id=1)  # 琴sir租户
```

**验证**:
- 软件分类租户: ✅ 琴sir (三国志)
- 用户租户: ✅ 琴sir (三国志)  
- 权限匹配: ✅ True
