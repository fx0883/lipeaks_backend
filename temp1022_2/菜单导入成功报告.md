## 🔍 导入命令说明

### 使用的命令

```bash
# 试运行（不实际写入数据库）
python manage.py import_feedback_menus --dry-run

# 正式导入
python manage.py import_feedback_menus

# 强制更新（如果菜单已存在）
python manage.py import_feedback_menus --force

# 指定文件路径
python manage.py import_feedback_menus --file path/to/menu_config.json
```

### 导入逻辑

1. **读取JSON文件**: 解析菜单配置
2. **递归处理**: 按层级导入菜单
3. **设置关系**: 自动建立父子关系
4. **字段映射**: JSON字段映射到模型字段
5. **冲突处理**: 
   - 默认跳过已存在的菜单
   - 使用 `--force` 可以强制更新

## 📌 注意事项

1. **唯一性约束**:
   - `name` 字段必须全局唯一
   - `code` 字段必须全局唯一
   - 如果有冲突会导入失败

2. **父子关系**:
   - 必须先导入父菜单
   - 子菜单的 parent_id 会自动设置

3. **权限字段**:
   - `roles` 为空数组表示所有人可见
   - `roles=['admin', 'super_admin']` 表示仅管理员可见

4. **隐藏菜单**:
   - `showLink=false` 的菜单不显示在侧边栏
   - 但路由仍然可以访问（如详情页）
