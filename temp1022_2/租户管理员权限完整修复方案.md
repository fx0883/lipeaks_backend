# 租户管理员权限完整修复方案

## 🎯 问题总结

**问题现象**: 租户管理员无法访问管理功能的API，返回403权限错误

**影响范围**:
- 统计API (`/feedbacks/statistics/`)
- 软件管理API (`/feedbacks/software-categories/`, `/feedbacks/software/` 等)
- 邮件模板API (`/feedbacks/email-templates/`)
- 系统健康检查API (`/feedbacks/health/`)

---

## 🔍 根本原因分析

### 问题1: is_staff 字段未正确设置

**原有逻辑** (`users/models.py`):
```python
if self.is_super_admin:
    self.is_staff = True
    self.is_superuser = True
```

**问题**: 只有超级管理员的 `is_staff=True`，租户管理员的 `is_staff=False`

**影响**: 使用 `is_staff` 判断权限的API会拒绝租户管理员

---

### 问题2: is_tenant_admin property 不可靠

**问题**: `is_tenant_admin` 是一个 @property，在某些情况下无法正确访问
- JWT Token中不包含property属性
- DRF序列化时property可能失效
- 权限检查时可能无法获取

**原有判断**:
```python
hasattr(request.user, 'is_tenant_admin') and request.user.is_tenant_admin
```

**可能失败的情况**:
- 从缓存或JWT恢复的用户对象
- 跨模块调用时的用户对象
- 序列化/反序列化后的对象

---

### 问题3: 权限检查不一致

**原有代码**: 有些视图使用权限类，有些手动检查
```python
# 方式1: 权限类（正确）
permission_classes = [SomePermission]

# 方式2: 手动检查（不可靠）
if not request.user.is_staff:
    return Response({'error': ...}, status=403)
```

## ✅ 完整修复方案

### 修复1: User模型 - 统一设置is_staff ✅

**文件**: `users/models.py` (第144-156行)

**修改后**:
```python
# 确保is_admin始终为True
self.is_admin = True

# 所有管理员用户都设置为staff
self.is_staff = True

# 超级管理员额外设置superuser权限
if self.is_super_admin:
    self.is_superuser = True
else:
    self.is_superuser = False
```

**效果**:
- ✅ 超级管理员: `is_staff=True, is_superuser=True`
- ✅ 租户管理员: `is_staff=True, is_superuser=False`

---

### 修复2: 创建可靠的is_tenant_admin判断函数 ✅

**文件**: `feedbacks/permissions.py` (第11-34行)

**新增辅助函数**:
```python
def is_tenant_admin(user):
    """
    Helper function to check if user is a tenant administrator
    
    Returns:
        bool: True if user is a tenant admin
    """
    # User must be authenticated
    if not user or not user.is_authenticated:
        return False
    
    # Check if this is a User model instance
    if not hasattr(user, 'is_admin'):
        return False
    
    # Must be admin but not super admin
    return (
        user.is_admin and 
        not getattr(user, 'is_super_admin', False)
    )
```

**优势**:
- ✅ 直接检查字段值，不依赖property
- ✅ 使用 `getattr` 避免属性不存在错误
- ✅ 明确检查 `is_admin` 字段
- ✅ 可以在任何地方调用
