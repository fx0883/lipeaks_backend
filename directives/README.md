# Directives 目录

此目录包含标准操作程序 (SOP) 文档，用于指导 AI Agent 完成各种任务。

## 文件格式

每个指令文件应包含以下部分：

1. **目标** - 任务的目的是什么
2. **输入** - 需要哪些输入参数
3. **执行工具** - 使用 `execution/` 目录中的哪些脚本
4. **输出** - 期望的输出结果
5. **边界情况** - 特殊情况的处理方式
6. **注意事项** - 需要注意的事项

## 可用指令

| 指令 | 描述 |
|------|------|
| `_template.md` | 指令模板，用于创建新指令 |

## 使用方式

1. 复制 `_template.md` 创建新指令
2. 填写各个部分
3. 确保 `execution/` 目录中有对应的脚本
