## 1. 系统概述

LiPeaks Backend 是一个基于 Django 5.2 和 Django REST Framework 构建的多租户 SaaS 平台后端，采用共享数据库、共享Schema的多租户隔离方案。

```mermaid
graph TB
    subgraph "LiPeaks Backend"
        subgraph "应用层"
            Django["Django 5.2"]
            DRF["Django REST Framework"]
            Celery["Celery (可选)"]
            Redis["Redis Cache"]
        end
        
        subgraph "数据层"
            MySQL["MySQL Database<br/>(共享数据库 + 共享Schema多租户)"]
        end
        
        Django --> MySQL
        DRF --> MySQL
        Celery --> Redis
    end
```

## 3. 请求处理流程

### 3.1 完整请求生命周期

```mermaid
sequenceDiagram
    participant C as 客户端
    participant WN as WhiteNoise
    participant SEC as SecurityMiddleware
    participant CORS as CorsMiddleware
    participant SESS as SessionMiddleware
    participant AUTH as APIAuthMiddleware
    participant TENANT as TenantMiddleware
    participant LOG as LoggingMiddleware
    participant RESP as ResponseStandardization
    participant VIEW as ViewSet
    participant DB as Database
    
    C->>WN: HTTP Request<br/>Headers: Authorization, X-Tenant-ID
    
    Note over WN: 1. 静态文件处理
    WN->>SEC: 非静态文件请求
    
    Note over SEC: 2. 安全头处理
    SEC->>CORS: 添加安全头后
    
    Note over CORS: 3. 跨域处理
    CORS->>SESS: CORS Headers
    
    Note over SESS: 4-7. Session/Locale/CSRF/Auth
    SESS->>AUTH: Django原生认证
    
    Note over AUTH: 8. JWT Token验证<br/>解析用户信息<br/>设置request.user_info
    AUTH->>TENANT: 用户信息已设置
    
    Note over TENANT: 9. 租户上下文设置<br/>X-Tenant-ID或user.tenant<br/>set_current_tenant()
    TENANT->>LOG: 租户上下文已设置
    
    Note over LOG: 10. 请求日志记录
    LOG->>VIEW: 日志记录完成
    
    VIEW->>DB: 执行业务逻辑<br/>TenantManager自动过滤
    DB-->>VIEW: 返回数据
    
    VIEW-->>RESP: Response
    Note over RESP: 11. 响应标准化<br/>统一JSON格式
    
    RESP-->>C: {success, code, message, data}
```

## 4. 认证授权流程

### 4.1 JWT登录流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    
    C->>S: POST /api/v1/auth/login/<br/>{username, password}<br/>Header: X-Tenant-ID (Member必须)
    
    S->>DB: 1. 查询用户
    DB-->>S: 用户数据
    
    Note over S: 2. 验证密码
    Note over S: 3. 检查用户状态
    Note over S: 4. 检查租户状态
    
    S->>S: 5. 生成JWT Token<br/>- access_token (短期)<br/>- refresh_token (长期)
    
    S-->>C: {<br/>  "access_token": "eyJ...",<br/>  "refresh_token": "eyJ...",<br/>  "user": {...}<br/>}
```

### 4.2 Token验证流程

```mermaid

    Permission ||--o{ RolePermission : "1:N"
```

### 7.2 权限检查流程

```mermaid
flowchart TB
    START["API请求"]

    S3["检查角色有效期<br/>start_date <= now<br/>end_date >= now (或为空)"]

    START --> S1 --> S2 --> S3 --> S4 --> S5

    S5 -->|No| DENY
```
