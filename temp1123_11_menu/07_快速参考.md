## 常用curl命令

### 1. 获取菜单列表
```bash
curl -X GET "http://localhost:8000/api/v1/menus/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 2. 创建菜单
```bash
curl -X POST "http://localhost:8000/api/v1/menus/" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "MyMenu",
    "code": "my_menu",
    "path": "/my-menu",
    "title": "我的菜单",
    "rank": 10
  }'
```

### 3. 获取菜单树
```bash
curl -X GET "http://localhost:8000/api/v1/menus/tree/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 4. 获取前端路由
```bash
curl -X GET "http://localhost:8000/api/v1/menus/admin/routes/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 5. 获取用户菜单
```bash
curl -X GET "http://localhost:8000/api/v1/menus/user/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 6. 分配菜单给用户
```bash
curl -X POST "http://localhost:8000/api/v1/menus/admins/3/menus/" \
  -H "Authorization: Bearer SUPER_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"menu_ids": [23, 28, 29]}'
```

## 菜单字段速查

### 必填字段
- `name` - 路由名称（唯一）
- `code` - 菜单编码（唯一）
- `path` - 路由路径
- `title` - 菜单标题

### 常用字段
- `icon` - 图标名称
- `rank` - 排序（越小越靠前）
- `parent_id` - 父菜单ID（null为顶级菜单）
- `is_active` - 是否启用
- `component` - 前端组件路径
- `redirect` - 重定向路径

### 权限字段
- `roles` - 页面级别权限（数组）
- `auths` - 按钮级别权限（数组）

### 显示控制
- `show_link` - 是否在菜单中显示
- `show_parent` - 是否显示父级菜单
- `keep_alive` - 是否缓存页面
- `hidden_tag` - 是否隐藏标签

## 前端集成代码片段

### Vue 3 + Composition API

#### 获取用户菜单
```javascript
import { ref, onMounted } from 'vue';
import axios from 'axios';

export function useUserMenus() {
  const menus = ref([]);
  const loading = ref(false);
  
  const fetchMenus = async () => {
    loading.value = true;
    try {
      const { data } = await axios.get('/api/v1/menus/user/', {
        headers: { 'Authorization': `Bearer ${getToken()}` }
      });
      if (data.success) {
        menus.value = data.data.menus;
      }
    } finally {
      loading.value = false;
    }
  };
  
  onMounted(fetchMenus);
  
  return { menus, loading, fetchMenus };
}
```

#### 递归菜单组件
```vue
<template>
  <el-menu>
    <template v-for="menu in menus" :key="menu.id">
      <el-sub-menu v-if="menu.children?.length" :index="menu.path">
        <template #title>
          <el-icon v-if="menu.icon"><component :is="menu.icon" /></el-icon>
          <span>{{ menu.title }}</span>
        </template>
        <MenuItems :menus="menu.children" />
      </el-sub-menu>
      
      <el-menu-item v-else :index="menu.path">
        <el-icon v-if="menu.icon"><component :is="menu.icon" /></el-icon>
        <span>{{ menu.title }}</span>
      </el-menu-item>
    </template>
  </el-menu>
</template>

<script setup>
defineProps({
  menus: { type: Array, required: true }
});
</script>
```

### React + Hooks

#### 获取用户菜单
```javascript
import { useState, useEffect } from 'react';
import axios from 'axios';

export function useUserMenus() {
  const [menus, setMenus] = useState([]);
  const [loading, setLoading] = useState(false);
  
  const fetchMenus = async () => {
    setLoading(true);
    try {
      const { data } = await axios.get('/api/v1/menus/user/', {
        headers: { 'Authorization': `Bearer ${getToken()}` }
      });
      if (data.success) {
        setMenus(data.data.menus);
      }
    } finally {
      setLoading(false);
    }
  };
  
  useEffect(() => {
    fetchMenus();
  }, []);
  
  return { menus, loading, fetchMenus };
}
```

#### 递归菜单组件
```jsx
const MenuItem = ({ menu }) => {
  if (menu.children?.length > 0) {
    return (
      <SubMenu 
        key={menu.id}
        icon={menu.icon}
        title={menu.title}
      >
        {menu.children.map(child => (
          <MenuItem key={child.id} menu={child} />
        ))}
      </SubMenu>
    );
  }
  
  return (
    <Menu.Item 
      key={menu.id}
      icon={menu.icon}
    >
      {menu.title}
    </Menu.Item>
  );
};
```

## 常见问题

### Q1: 租户管理员和超级管理员的区别？
**A**: 
- 租户管理员：可以查看和创建菜单，但不能更新、删除或为其他用户分配菜单
- 超级管理员：拥有所有权限，可以进行所有操作

### Q2: 如何创建多级菜单？
**A**: 
1. 先创建父菜单（parent_id为null）
2. 再创建子菜单，设置parent_id为父菜单的ID
3. 可以继续创建孙菜单，设置parent_id为子菜单的ID

### Q3: 菜单树和菜单列表有什么区别？
**A**:
- 菜单列表：返回平铺的菜单数组，支持分页
- 菜单树：返回嵌套的树形结构，子菜单在children字段中

### Q4: 如何控制菜单的排序？
**A**: 使用rank字段，数值越小排序越靠前。同级菜单按rank排序，rank相同时按ID排序。

### Q5: admin/routes和user接口有什么区别？
**A**:
- admin/routes：返回前端路由格式（驼峰命名），用于配置路由系统
- user：返回完整菜单数据（下划线命名），用于渲染菜单

### Q6: 分配菜单时是替换还是追加？
**A**: 是替换。调用分配接口时，会替换用户现有的所有菜单分配。

### Q7: 删除父菜单会发生什么？
**A**: 会同时删除该菜单的所有子菜单和孙菜单。

### Q8: 如何实现菜单权限控制？
**A**: 
1. 使用roles字段设置页面级别权限
2. 使用auths字段设置按钮级别权限
3. 前端根据用户角色判断是否显示/可操作

## 性能优化建议

### 1. 缓存策略
```javascript
// 使用localStorage缓存菜单
const CACHE_KEY = 'user_menus';
const CACHE_TIME = 30 * 60 * 1000; // 30分钟

function getCachedMenus() {
  const cached = localStorage.getItem(CACHE_KEY);
  if (cached) {
    const { data, timestamp } = JSON.parse(cached);
    if (Date.now() - timestamp < CACHE_TIME) {
      return data;
    }
  }
  return null;
}

function setCachedMenus(menus) {
  localStorage.setItem(CACHE_KEY, JSON.stringify({
    data: menus,
    timestamp: Date.now()
  }));
}
```

### 2. 按需加载
```javascript
// 延迟加载组件
const routes = menus.map(menu => ({
  path: menu.path,
  component: () => import(`@${menu.component}`)
}));
```

### 3. 批量操作
```javascript
// 批量为多个用户分配相同菜单
async function batchAssignMenus(userIds, menuIds) {
  return Promise.all(
    userIds.map(userId => 
      assignMenus(userId, menuIds)
    )
  );
}
```

## 安全建议

1. **Token管理**: 妥善保管Token，不要暴露在公开代码中
2. **HTTPS**: 生产环境必须使用HTTPS
3. **权限验证**: 前端也要做权限验证，不要只依赖后端
4. **敏感操作**: 删除、批量操作等敏感操作需要二次确认
5. **日志记录**: 记录重要操作的日志
