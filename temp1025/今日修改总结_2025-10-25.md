## 🚀 优化1：邮件发送线程池优化

### 问题
API 调用时，邮件验证和发送操作阻塞请求，导致：
- 响应时间长（6-10秒）
- 经常超时

### 解决方案
使用线程池异步处理邮件相关操作，API 立即返回

### 技术实现

**新增文件**：
- `feedbacks/services.py` - 添加 `EmailThreadPoolManager` 类
- `feedbacks/management/commands/test_api_performance.py` - API 性能测试工具
- `feedbacks/management/commands/monitor_email_threads.py` - 线程池监控工具

**核心代码**：
```python
class EmailThreadPoolManager:
    """邮件发送线程池管理器 - 单例模式"""
    def __init__(self):
        self.max_workers = getattr(settings, 'EMAIL_THREAD_POOL_SIZE', 3)
        self.executor = ThreadPoolExecutor(
            max_workers=self.max_workers,
            thread_name_prefix='email-sender'
        )
    
    def submit_email_task(self, task_func, *args, **kwargs):
        """提交邮件任务到线程池"""
        future = self.executor.submit(task_func, *args, **kwargs)
        return future
```

**处理流程**：
```
API请求 → 创建回复 → 提交线程池任务 → API响应 (2秒) ✅
                            ↓
                    后台线程池 → 邮件验证 → 邮件发送
```

### 性能提升

| 阶段 | 响应时间 | 说明 |
|-----|---------|------|
| 最初 | >10秒（超时） | 同步邮件发送阻塞 |
| 禁用同步降级 | ~6秒 | 减少SMTP等待 |
| **线程池优化** | **~2秒** | ✅ **立即返回** |

**提升幅度**：80%+

## 🛠️ 优化4：Member 用户支持修复

### 问题
Member 用户提交反馈返回 500 错误：
```
"Cannot assign \"<Member: fx0883>\": \"Feedback.user\" must be a \"User\" instance."
```

### 根因
- Feedback.user 字段是 ForeignKey(User)
- Member 和 User 是不同的模型表
- 不能将 Member 实例赋值给 User 外键

### 解决方案

**修改1：创建反馈时的用户类型检查**
```python
# 通过表名判断用户类型
user_table_name = request.user._meta.db_table
if user_table_name == 'user':  # 只有User类型才设置
    validated_data['user'] = request.user
# Member 类型不设置，保持 None
```

**修改2：投票查询时的用户类型检查**
```python
def get_user_vote(self, obj):
    user_table_name = request.user._meta.db_table
    if user_table_name == 'user':
        vote = obj.votes.filter(user=request.user).first()
    return None  # Member 用户返回 None
```

**修改3：Email 改为可选（已登录用户）**
```python
# 只有匿名用户才强制要求email
if not request or not request.user.is_authenticated:
    if not attrs.get('contact_email'):
        raise ValidationError(...)
# 已登录用户（User或Member）email可选
```

### 用户类型对比

| 特性 | User 用户 | Member 用户 | 匿名用户 |
|-----|----------|-----------|---------|
| 设置 user 字段 | ✅ | ❌ (为None) | ❌ |
| 投票功能 | ✅ | ❌ | ❌ |
| Email 必填 | ❌ 可选 | ❌ 可选 | ✅ 必填 |
| 自动填充 contact | ✅ | ✅ | ❌ |
