## 🔍 命名模式分析

### 发现的命名模式

**模式1：纯数字重复** (最常见)
```
错误：1_1.png, 10_10.png, 100_100.png
正确：1.png, 10.png, 100.png
```

**模式2：带 _small 后缀的重复**
```
错误：1_1_small.png, 10_10_small.png
正确：1_small.png, 10_small.png
```

**模式3：带 _colored 后缀（不需要修复）**
```
正确：1000_colored.png, 1001_colored.png
说明：这是合法的命名，不是重复
```

### 正则表达式匹配

```python
# 匹配 {num}_{num}_small
r'^(\d+)_\1_small$'

# 匹配 {num}_{num}
r'^(\d+)_\1$'

# \1 表示反向引用第一个捕获组，检测重复
```

**示例**：
- `1_1` → 匹配，group(1)='1'，重复 ✅
- `1_2` → 不匹配，不重复 ❌
- `1000_colored` → 不匹配，不是重复 ❌

## 🎯 修复规则详解

### 规则1：文件大小规则

```
IF file_size(xxx_small.ext) > file_size(xxx.ext) THEN
    交换文件名
END IF
```

### 规则2：重复数字规则

```python
# 检测并修复重复数字
if filename matches r'^(\d+)_\1(_small)?\.ext$':
    # 1_1.png → 1.png
    # 10_10_small.png → 10_small.png
    remove_duplicate_number()

# 保留非重复模式
if filename matches r'^\d+_\w+\.ext$':
    # 1000_colored.png → 保持不变（不是重复）
    keep_as_is()
```

### 规则3：命名一致性规则

```
inspiration 文件夹命名 == 外层文件夹命名

示例：
60/ → 1.png, 1_small.png
60/inspiration/ → 1.png, 1_small.png ✅ 必须一致
```
