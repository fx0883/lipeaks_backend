## 📋 三个阶段的修复

### 阶段1：文件大小与命名不匹配 ✅

**问题描述**：
- `_small` 后缀的文件反而比普通文件更大
- 大小关系完全颠倒

**示例问题**：
```
❌ 1.png (105KB) - 实际是小图
❌ 1_small.png (237KB) - 实际是大图
```

**修复方法**：
- 比较每对图片的文件大小
- 如果 `_small` 文件更大，交换文件名

**修复结果**：
- 扫描：9,603 组图片
- 修复：1,984 组
- 成功率：100%

**修复后**：
```
✅ 1.png (237KB) - 大图
✅ 1_small.png (105KB) - 小图
```

---

### 阶段2：文件名重复数字 ✅

**问题描述**：
- inspiration 文件夹中文件名重复了数字
- 与外层文件夹命名不一致

**示例问题**：
```
外层：1.png, 10.png, 201.png
Inspiration：
  ❌ 1_1.png - 重复了数字"1"
  ❌ 10_10.png - 重复了数字"10"
  ❌ 201_201.png - 重复了数字"201"
```

**修复方法**：
- 使用正则表达式检测 `{num}_{num}` 模式
- 重命名去掉重复的数字部分

**正则模式**：
```python
r'^(\d+)_\1(_small)?\.ext$'
# \1 是反向引用，检测重复
```

**修复结果**：
- 处理：24 个 inspiration 文件夹
- 修复：15 个文件夹
- 重命名：3,701 个文件
- 成功率：100%

**修复后**：
```
✅ 1.png
✅ 10.png
✅ 201.png
```

IF 外层没有 _colored 后缀 THEN

**修复方法**：

## 🔍 问题根源分析

### 为什么会出现这些问题？

**问题1：大小颠倒**
- 可能原因：批量处理时搞混了大图和小图
- 影响：20.7% 的图片（1,984 组）

**问题2：重复数字**
- 可能原因：导出或复制时使用了错误的命名脚本
- 影响：15 个 inspiration 文件夹（3,701 文件）

**问题3：_colored 后缀**
- 可能原因：部分图片是彩色版本，但后来改为统一命名
- 影响：12 个 inspiration 文件夹（5,417 文件）

### 为什么 inspiration 文件夹问题特别多？

**分析**：
- Inspiration 可能是后期批量导入的
- 使用了不同的命名规则或脚本
- 没有与外层文件夹保持一致

## 🎯 最终命名规范

### 标准格式

```
大图：{id}.{ext}
小图：{id}_small.{ext}

示例：
✅ 1.png, 1_small.png
✅ 10.png, 10_small.png
✅ 201.png, 201_small.png
✅ 1000.png, 1000_small.png

❌ 1_1.png（重复数字）
❌ 1000_colored.png（不必要的后缀，当外层没有时）
```

### 特殊情况

**如果外层本身有特殊后缀**：
```
外层：1000_colored.png
Inspiration：1000_colored.png ✅ 保持一致
```

**支持的扩展名**：
- .png
- .jpg
- .jpeg
