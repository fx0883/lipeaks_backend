# 图片路径修复说明

## 📋 问题分析

### 发现的问题

**导入后的路径**（错误）：
```
cover_image: "images/60/1.png" ❌
cover_image_small: "images/60/1_small.png" ❌
```

**期望的路径**（正确）：
```
cover_image: "/media/images/60/1.png" ✅
cover_image_small: "/media/images/60/1_small.png" ✅
```

**缺少的部分**：
- ❌ 缺少前导斜杠 `/`
- ❌ 缺少 `media/` 目录前缀

---

## 🔍 原因分析

### 代码问题定位

**原始代码（错误）**：
```python
# 构建相对路径
relative_path = file.relative_to(Path('media'))
cover_image = str(relative_path).replace('\\', '/')
# 结果：images/60/1.png ❌
```

**问题**：
1. `relative_to(Path('media'))` 会去掉 `media/` 部分
2. 没有添加前导斜杠 `/`
3. 导致最终路径不完整

### 正确的做法

**方法1：保留完整路径**
```python
cover_image = f"/{file.as_posix()}"
# 结果：/media/images/60/1.png ✅
```

**方法2：手动添加前缀**
```python
relative_path = file.relative_to(Path('media'))
cover_image = f"/media/{str(relative_path).replace('\\', '/')}"
# 结果：/media/images/60/1.png ✅
```

## ✅ 修复方案

### 修复逻辑

```python
for article in articles:
    # 检查 cover_image
    if article.cover_image:
        if article.cover_image.startswith('images/'):
            # 添加 /media/ 前缀
            article.cover_image = f"/media/{article.cover_image}"
    
    # 检查 cover_image_small
    if article.cover_image_small:
        if article.cover_image_small.startswith('images/'):
            # 添加 /media/ 前缀
            article.cover_image_small = f"/media/{article.cover_image_small}"
    
    article.save()
```

## 📝 为什么需要 /media/ 前缀

### Django 媒体文件处理

**Django 配置**（settings.py）：
```python
MEDIA_URL = '/media/'
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')
```

**URL 映射**（urls.py）：
```python
from django.conf import settings
from django.conf.urls.static import static

urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

**访问规则**：
```
文件物理路径：/path/to/project/media/images/60/1.png
数据库存储：/media/images/60/1.png
访问URL：http://localhost:8000/media/images/60/1.png
```

### 序列化器处理

**CMS 的序列化器会自动添加域名**：
```python
def get_cover_image(self, obj):
    if not obj.cover_image:
        return ""
    
    request = self.context.get('request')
    if request is not None:
        return add_domain_to_image_url(request, obj.cover_image)
    
    return obj.cover_image
```

```

↓
序列化器处理
↓
```
