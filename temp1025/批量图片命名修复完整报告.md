## 🎯 修复规则说明

### 核心规则

**规则1：大小判断**
```
IF file_size(xxx_small.ext) > file_size(xxx.ext) THEN
    需要交换文件名
END IF
```

**规则2：命名规范**
```
- 大图：xxx.ext（不带_small后缀）
- 小图：xxx_small.ext（带_small后缀）
```

**规则3：文件大小关系**
```
必须满足：
file_size(xxx.ext) ≥ file_size(xxx_small.ext)
```

### 特殊情况处理

**情况1：大小相等**
```
xxx.png (50KB) = xxx_small.png (50KB)
处理：仍然交换（因为_small应该更小或相等）
```

**情况2：0字节文件**
```
xxx.png (0KB) < xxx_small.png (100KB)
处理：交换（0字节的肯定不是大图）
```

**情况3：扩展名不同**
```
xxx.png (100KB)
xxx_small.jpg (50KB)
处理：支持交换，保持各自的扩展名
```
