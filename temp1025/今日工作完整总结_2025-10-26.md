### ViewSet → APIView 迁移

**迁移前**：
- 使用 ViewSet + Router
- 隐式路由配置
- 难以调试

**迁移后**：
- 100% 使用 APIView
- 显式 path() 配置
- 易于调试和控制

**统计**：
- 移除 ViewSet：6 个
- 新增 APIView：16 个
- 移除 Router：完全移除

### 租户隔离增强

**所有 API 都支持 Tenant-ID header**：
```javascript
fetch('/api/v1/feedbacks/feedbacks/', {
  headers: {
    'X-Tenant-ID': '1'  // 租户过滤
  }
})
```

**三层租户保护**：
1. 查询过滤：`queryset.filter(tenant=tenant)`
2. 对象验证：`if obj.tenant != tenant: return 404`
3. 创建设置：`serializer.save(tenant=tenant)`
