### 步骤3：重新命名文件

- ✅ **大文件**：不带 `_small` 后缀

```
1. xxx.png → xxx_temp.png
2. xxx_small.png → xxx.png
3. xxx_temp.png → xxx_small.png
```

**验证方法**：
1. 重新扫描所有修复过的文件夹

```python
def fix_image_naming(directory):
    """修复图片命名的核心算法"""
    
    # 1. 扫描和分组
    image_groups = group_image_pairs(directory)
    
    # 2. 检测错误命名
    for base_name, files in image_groups.items():
        normal_file = files['normal']  # xxx.png
        small_file = files['small']    # xxx_small.png
        
        if small_file.size > normal_file.size:
            # 3. 交换文件名
            swap_files(normal_file, small_file)
    
    # 4. 验证结果

```

### 文件名提取

```python
def get_base_name(filename):
    """
    提取基础名称
    例如：
      '1.png' -> '1'
      '1_small.png' -> '1'
      'abc_123_small.jpg' -> 'abc_123'
    """
    name_without_ext = Path(filename).stem
    if name_without_ext.endswith('_small'):
        return name_without_ext[:-6]
    return name_without_ext
```

### 安全交换

```python
def swap_files(file_a, file_b):
    """
    安全交换两个文件的名称
    使用临时文件避免冲突
    """
    temp_file = "temp_file"
    
    shutil.move(file_a, temp_file)   # A → temp
    shutil.move(file_b, file_a)      # B → A
    shutil.move(temp_file, file_b)   # temp → B
```

## 🔧 命名规范详解

### 通用命名规则

**基础格式**：
```
{基础名称}.{扩展名}        - 大图
{基础名称}_small.{扩展名}  - 小图
```

**基础名称可以是**：
- 数字：`1`, `201`, `1234`
- 字母：`a`, `abc`, `image`
- 组合：`abc_123`, `img_1`, `photo_2025`

**判断标准**：
- 比较文件大小
- 大文件 = 正常文件（不带 _small）
- 小文件 = 缩略图（带 _small）

### 示例对比

**正确的命名**：
```
✅ 1.png (200KB) + 1_small.png (80KB)
✅ photo_123.jpg (300KB) + photo_123_small.jpg (120KB)
✅ abc.png (150KB) + abc_small.png (60KB)
```

**错误的命名**（已修复）：
```
❌ 1.png (80KB) + 1_small.png (200KB)  → 交换后正确
❌ photo.jpg (100KB) + photo_small.jpg (250KB)  → 交换后正确
```

```python
from pathlib import Path

def verify_folder(folder_path):
    """验证文件夹图片命名是否正确"""
    error_count = 0
    
    for normal_file in folder_path.glob("*.png"):
        if not normal_file.stem.endswith('_small'):
            base_name = normal_file.stem
            small_file = folder_path / f"{base_name}_small.png"
            
            if small_file.exists():
                normal_size = normal_file.stat().st_size
                small_size = small_file.stat().st_size
                
                if small_size > normal_size:
                    print(f"[ERROR] {base_name}")
                    error_count += 1
    
    return error_count == 0
```
