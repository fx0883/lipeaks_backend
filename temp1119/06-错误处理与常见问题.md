# 错误处理与常见问题

本文档说明所有可能的错误情况及其处理方法。

## 错误码对照表

### 业务错误码

| 错误码 | HTTP状态 | error_code | 说明 | 解决方案 |
|--------|----------|------------|------|----------|
| 4000 | 400 | VALIDATION_ERROR | 数据验证失败 | 检查请求参数是否正确 |
| 4010 | 401 | AUTHENTICATION_FAILED | 未认证 | 用户需要登录 |
| 4011 | 401 | TOKEN_EXPIRED | Token 过期 | 使用 refresh_token 刷新 |
| 4012 | 401 | INVALID_TOKEN | Token 无效 | 重新登录 |
| 4030 | 403 | PERMISSION_DENIED | 权限不足 | 确认用户是 Member 类型 |
| 4040 | 404 | NOT_FOUND | 资源不存在 | 确认文章 ID 是否正确 |
| 4090 | 400 | DUPLICATE_OPERATION | 重复操作 | 已经点赞过该文章 |
| 5000 | 500 | INTERNAL_ERROR | 服务器内部错误 | 联系技术支持 |

## 常见错误及处理

### 1. 重复点赞错误

**错误示例：**
```json
{
  "success": false,
  "code": 4000,
  "message": "数据验证失败",
  "data": {
    "article": ["您已经点赞过这篇文章"]
  },
  "error_code": "VALIDATION_ERROR"
}
```

**原因：**
- 用户已经点赞过该文章，再次调用点赞接口

**解决方案：**
```typescript
// 前端应该先检查点赞状态
const checkAndLike = async (articleId: number) => {
  // 1. 先检查状态
  const status = await checkLikeStatus(articleId);
  
  // 2. 如果未点赞才执行点赞
  if (!status.data.is_liked) {
    await likeArticle(articleId);
  } else {
    console.log('已经点赞过了');
  }
};
```

### 2. 未认证错误

**错误示例：**
```json
{
  "success": false,
  "code": 4010,
  "message": "认证失败",
  "error_code": "AUTHENTICATION_FAILED"
}
```

**原因：**
- 请求头缺少 Authorization
- Token 不存在或格式错误

**解决方案：**
```typescript
// 确保每个请求都携带 token
const config = {
  headers: {
    'Authorization': `Bearer ${localStorage.getItem('access_token')}`,
    'X-Tenant-ID': localStorage.getItem('tenant_id')
  }
};

// 或使用 axios 拦截器统一处理
axios.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token');
  if (!token) {
    // 跳转到登录页
    window.location.href = '/login';
    return Promise.reject('No token');
  }
  config.headers.Authorization = `Bearer ${token}`;
  return config;
});
```

### 3. Token 过期错误

**错误示例：**
```json
{
  "success": false,
  "code": 4011,
  "message": "Token已过期",
  "error_code": "TOKEN_EXPIRED"
}
```

**解决方案：**
```typescript
// 使用 refresh_token 刷新 access_token
const refreshAccessToken = async () => {
  const refreshToken = localStorage.getItem('refresh_token');
  
  try {
    const response = await axios.post('/api/v1/auth/token/refresh/', {
      refresh: refreshToken
    });
    
    const newAccessToken = response.data.access_token;
    localStorage.setItem('access_token', newAccessToken);
    
    return newAccessToken;
  } catch (error) {
    // refresh_token 也过期了，需要重新登录
    localStorage.clear();
    window.location.href = '/login';
  }
};

// 在响应拦截器中自动处理
axios.interceptors.response.use(
  response => response,
  async error => {
    const originalRequest = error.config;
    
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      
      const newToken = await refreshAccessToken();
      originalRequest.headers.Authorization = `Bearer ${newToken}`;
      
      return axios(originalRequest);
    }
    
    return Promise.reject(error);
  }
);
```

### 4. 权限不足错误

**错误示例：**
```json
{
  "success": false,
  "code": 4030,
  "message": "只有Member用户可以点赞文章",
  "error_code": "PERMISSION_DENIED"
}
```

**原因：**
- 当前用户不是 Member 类型（可能是 Admin 用户）
- 尝试操作其他租户的资源

**解决方案：**
```typescript
// 1. 前端检查用户类型
const userInfo = JSON.parse(localStorage.getItem('user_info'));

if (userInfo.user_type !== 'member') {
  // 隐藏或禁用点赞功能
  showLikeButton = false;
}

// 2. 确保租户 ID 正确
const tenantId = userInfo.tenant_id;
axios.defaults.headers.common['X-Tenant-ID'] = tenantId;
```

### 5. 文章不存在错误

**错误示例：**
```json
{
  "success": false,
  "code": 4040,
  "message": "文章不存在",
  "error_code": "NOT_FOUND"
}
```

**原因：**
- 文章 ID 错误
- 文章已被删除
- 文章不属于当前租户

**解决方案：**
```typescript
// 添加错误处理
try {
  await likeArticle(articleId);
} catch (error) {
  if (error.response?.status === 404) {
    alert('文章不存在或已被删除');
    // 跳转到文章列表页
    window.location.href = '/articles';
  }
}
```

## 完整的错误处理示例

### React 错误边界

```typescript
// components/ErrorBoundary.tsx
import React, { Component, ErrorInfo, ReactNode } from 'react';

interface Props {
  children: ReactNode;
}

interface State {
  hasError: boolean;
  error: Error | null;
}

export class ErrorBoundary extends Component<Props, State> {
  public state: State = {
    hasError: false,
    error: null
  };

  public static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error };
  }

  public componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    console.error('Uncaught error:', error, errorInfo);
  }

  public render() {
    if (this.state.hasError) {
      return (
        <div className="error-container">
          <h2>出错了</h2>
          <p>{this.state.error?.message}</p>
          <button onClick={() => this.setState({ hasError: false, error: null })}>
            重试
          </button>
        </div>
      );
    }

    return this.props.children;
  }
}
```

### 统一错误处理函数

```typescript
// utils/errorHandler.ts
interface ApiError {
  success: boolean;
  code: number;
  message: string;
  error_code?: string;
  data?: any;
}

export const handleApiError = (error: any): string => {
  // 网络错误
  if (!error.response) {
    if (!navigator.onLine) {
      return '网络连接失败，请检查网络';
    }
    return '请求超时，请重试';
  }

  const { status, data } = error.response;
  const apiError = data as ApiError;

  // 根据错误码返回友好提示
  switch (apiError.error_code) {
    case 'AUTHENTICATION_FAILED':
    case 'TOKEN_EXPIRED':
    case 'INVALID_TOKEN':
      localStorage.clear();
      window.location.href = '/login';
      return '登录已过期，请重新登录';

    case 'PERMISSION_DENIED':
      return '权限不足，无法执行此操作';

    case 'NOT_FOUND':
      return '请求的资源不存在';

    case 'VALIDATION_ERROR':
      // 返回具体的验证错误信息
      if (apiError.data) {
        const errors = Object.values(apiError.data).flat();
        return errors.join(', ');
      }
      return apiError.message || '请求参数错误';

    case 'DUPLICATE_OPERATION':
      return '您已经执行过此操作';

    case 'INTERNAL_ERROR':
      return '服务器错误，请稍后重试';

    default:
      return apiError.message || '操作失败，请重试';
  }
};

// 使用示例
try {
  await likeArticle(articleId);
} catch (error) {
  const errorMessage = handleApiError(error);
  alert(errorMessage);
  // 或使用 toast/notification 组件显示错误
}
```

## FAQ

### Q1: 为什么一直提示"未认证"？
**A**: 检查以下几点：
1. localStorage 中是否有 access_token
2. token 格式是否正确（Bearer + 空格 + token）
3. token 是否过期
4. 请求头是否正确设置

### Q2: 点赞成功但数量没有更新？
**A**: 检查以下几点：
1. 是否正确更新了本地状态
2. 是否有缓存问题
3. 重新获取文章详情

### Q3: 如何测试 Token 过期情况？
**A**: 
```typescript
// 使用一个过期的 token 进行测试
localStorage.setItem('access_token', 'expired_token');
// 然后调用 API，观察是否正确处理
```
