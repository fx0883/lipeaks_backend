## 请求数据结构

### ArticleLikeCreate (点赞请求)

用于创建点赞记录的请求体。

```typescript
interface ArticleLikeCreateRequest {
  article: number;  // 文章 ID，必填
}
```

#### 字段说明

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| article | integer | 是 | 要点赞的文章 ID | 100 |

#### 验证规则
- `article` 必须是有效的文章 ID
- 文章必须属于当前租户
- 用户不能重复点赞同一文章

#### 示例

```json
{
  "article": 100
}
```

## 响应数据结构

### 1. ArticleLike (点赞详情)

完整的点赞记录信息。

```typescript
interface ArticleLike {
  id: number;                           // 点赞记录 ID
  from_member: number;                  // 点赞用户 ID
  article: number;                      // 文章 ID
  article_detail: ArticleDetail;        // 文章详细信息（嵌套对象）
  from_member_info: MemberInfo;         // 点赞用户信息（嵌套对象）
  tenant: number;                       // 租户 ID
  created_at: string;                   // 点赞时间（ISO 8601）
  ip_address: string | null;            // IP 地址
  user_agent: string | null;            // 用户代理
}
```

#### 字段说明

| 字段名 | 类型 | 可空 | 说明 |
|--------|------|------|------|
| id | integer | 否 | 点赞记录唯一标识 |
| from_member | integer | 否 | 点赞发起者的 Member ID |
| article | integer | 否 | 被点赞文章的 ID |
| article_detail | object | 否 | 文章详细信息（见 ArticleDetail） |
| from_member_info | object | 否 | 点赞用户信息（见 MemberInfo） |
| tenant | integer | 否 | 租户 ID |
| created_at | string | 否 | 点赞时间，ISO 8601 格式 |
| ip_address | string | 是 | 点赞时的 IP 地址 |
| user_agent | string | 是 | 点赞时的浏览器信息 |

### 2. LikeStatus (点赞状态)

用于检查文章点赞状态的响应。

```typescript
interface LikeStatus {
  is_liked: boolean;          // 是否已点赞
  like_id: number | null;     // 点赞记录 ID（已点赞时返回）
  created_at: string | null;  // 点赞时间（已点赞时返回）
}
```

#### 字段说明

| 字段名 | 类型 | 可空 | 说明 |
|--------|------|------|------|
| is_liked | boolean | 否 | 是否已点赞 |
| like_id | integer | 是 | 点赞记录 ID（未点赞时为 null） |
| created_at | string | 是 | 点赞时间（未点赞时为 null） |

#### 已点赞示例

```json
{
  "is_liked": true,
  "like_id": 45,
  "created_at": "2024-01-20T10:30:00.123456Z"
}
```

#### 未点赞示例

```json
{
  "is_liked": false,
  "like_id": null,
  "created_at": null
}
```

### 3. PaginatedResponse (分页响应)

列表接口的分页响应结构。

```typescript
interface PaginatedResponse<T> {
  pagination: PaginationInfo;  // 分页信息
  results: T[];                // 结果列表
}

interface PaginationInfo {
  count: number;          // 总记录数
  next: string | null;    // 下一页 URL
  previous: string | null;// 上一页 URL
  page_size: number;      // 每页数量
  current_page: number;   // 当前页码
  total_pages: number;    // 总页数
}
```

#### 字段说明

**PaginationInfo**

| 字段名 | 类型 | 可空 | 说明 |
|--------|------|------|------|
| count | integer | 否 | 总记录数 |
| next | string | 是 | 下一页的完整 URL（最后一页时为 null） |
| previous | string | 是 | 上一页的完整 URL（第一页时为 null） |
| page_size | integer | 否 | 每页显示的记录数 |
| current_page | integer | 否 | 当前页码（从 1 开始） |
| total_pages | integer | 否 | 总页数 |

#### 示例

```json
{
  "pagination": {
    "count": 25,
    "next": "http://api.example.com/api/v1/interactions/article-likes/?page=2",
    "previous": null,
    "page_size": 10,
    "current_page": 1,
    "total_pages": 3
  },
  "results": [
    // ArticleLike 对象数组
  ]
}
```

### 4. StandardResponse (统一响应格式)

所有 API 都使用统一的响应格式。

```typescript
interface StandardResponse<T> {
  success: boolean;       // 操作是否成功
  code: number;           // 响应码
  message: string;        // 响应消息
  data: T;                // 响应数据
  error_code?: string;    // 错误码（失败时返回）
}
```

#### 字段说明

| 字段名 | 类型 | 必有 | 说明 |
|--------|------|------|------|
| success | boolean | 是 | 操作是否成功 |
| code | integer | 是 | 业务响应码（见响应码说明） |
| message | string | 是 | 响应消息（中文） |
| data | any | 是 | 响应数据（具体类型根据接口而定） |
| error_code | string | 否 | 错误码（仅失败时返回） |

#### 成功响应示例

```json
{
  "success": true,
  "code": 2000,
  "message": "操作成功",
  "data": {
    "id": 45,
    "article": 100
    // ... 其他字段
  }
}
```

#### 错误响应示例

```json
{
  "success": false,
  "code": 4000,
  "message": "数据验证失败",
  "data": {
    "article": ["您已经点赞过这篇文章"]
  },
  "error_code": "VALIDATION_ERROR"
}
```

## 嵌套对象说明

### ArticleDetail (文章详情)

```typescript
interface ArticleDetail {
  id: number;                    // 文章 ID
  title: string;                 // 文章标题
  slug: string;                  // URL slug
  excerpt: string;               // 摘要
  cover_image: string;           // 封面图（大图）
  cover_image_small: string;     // 封面图（小图）
  author_info: AuthorInfo;       // 作者信息
  author_type: string;           // 作者类型
  status: string;                // 发布状态
  is_featured: boolean;          // 是否精选
  is_pinned: boolean;            // 是否置顶
  published_at: string | null;   // 发布时间
  created_at: string;            // 创建时间
  updated_at: string;            // 更新时间
  categories: Category[];        // 分类列表
  tags: Tag[];                   // 标签列表
  comments_count: number;        // 评论数
  likes_count: number;           // 点赞数
  views_count: number;           // 浏览数
  parent?: number;               // 父文章 ID
  parent_info?: ParentInfo;      // 父文章信息
  children_count?: number;       // 子文章数量
}
```

#### 字段说明

| 字段名 | 类型 | 可空 | 说明 |
|--------|------|------|------|
| id | integer | 否 | 文章唯一标识 |
| title | string | 否 | 文章标题 |
| slug | string | 否 | SEO 友好的 URL 标识 |
| excerpt | string | 否 | 文章摘要/简介 |
| cover_image | string | 否 | 封面图片完整 URL |
| cover_image_small | string | 否 | 封面图片缩略图 URL |
| author_info | object | 否 | 作者详细信息 |
| author_type | string | 否 | 作者类型：`member` 或 `admin` |
| status | string | 否 | 发布状态（见枚举值说明） |
| is_featured | boolean | 否 | 是否为精选文章 |
| is_pinned | boolean | 否 | 是否置顶 |
| published_at | string | 是 | 发布时间（草稿时为 null） |
| created_at | string | 否 | 创建时间 |
| updated_at | string | 否 | 最后更新时间 |
| categories | array | 否 | 文章所属分类列表 |
| tags | array | 否 | 文章标签列表 |
| comments_count | integer | 否 | 评论总数 |
| likes_count | integer | 否 | 点赞总数 |
| views_count | integer | 否 | 浏览总数 |
| parent | integer | 是 | 父文章 ID（如果是子文章） |
| parent_info | object | 是 | 父文章信息 |
| children_count | integer | 是 | 子文章数量 |

## 响应码说明

### 成功响应码

| 响应码 | 说明 |
|--------|------|
| 2000 | 操作成功 |
| 2001 | 创建成功 |
| 2002 | 更新成功 |
| 2003 | 删除成功 |

### 错误响应码

| 响应码 | 说明 | error_code |
|--------|------|------------|
| 4000 | 请求参数错误 | VALIDATION_ERROR |
| 4010 | 未认证 | AUTHENTICATION_FAILED |
| 4011 | Token 过期 | TOKEN_EXPIRED |
| 4012 | Token 无效 | INVALID_TOKEN |
| 4030 | 权限不足 | PERMISSION_DENIED |
| 4040 | 资源不存在 | NOT_FOUND |
| 4090 | 重复操作 | DUPLICATE_OPERATION |
| 5000 | 服务器内部错误 | INTERNAL_ERROR |
