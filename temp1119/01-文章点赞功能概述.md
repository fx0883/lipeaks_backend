## 📌 功能概述

文章点赞功能允许 **Member 用户**对文章进行点赞操作，支持查看点赞列表、检查点赞状态等功能。

### 核心特性

✅ **点赞/取消点赞**
- 用户可以对文章进行点赞
- 支持取消点赞
- 防止重复点赞

✅ **点赞状态查询**
- 快速检查文章是否已被当前用户点赞
- 返回点赞时间和记录 ID

✅ **列表查询**
- 查看我点赞的所有文章
- 查看某篇文章的所有点赞用户
- 支持分页

✅ **实时统计**
- 点赞/取消点赞后，文章的 `likes_count` 自动更新
- 数据实时同步

## 🔐 权限要求

### 用户类型限制
- ✅ **Member 用户**：可以使用所有点赞功能
- ❌ **Admin 用户**：不能使用点赞功能
- ❌ **未登录用户**：不能使用点赞功能

### 认证方式
使用 **JWT Token** 进行认证：
```
Authorization: Bearer {access_token}
```

### 租户隔离
所有请求必须携带租户 ID：
```
X-Tenant-ID: {tenant_id}
```

## 🚀 快速开始

### 1. 获取 Access Token

首先需要使用 Member 账号登录获取 token：

```bash
POST /api/v1/auth/member/login/
Content-Type: application/json
X-Tenant-ID: 1

{
  "username": "member_user",
  "password": "password123"
}
```

**响应示例：**
```json
{
  "success": true,
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 5,
      "username": "member_user",
      "tenant_id": 1
    }
  }
}
```

### 2. 点赞文章

使用获取的 token 进行点赞：

```bash
POST /api/v1/interactions/article-likes/
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
X-Tenant-ID: 1
Content-Type: application/json

{
  "article": 100
}
```

**响应示例：**
```json
{
  "success": true,
  "code": 2000,
  "message": "操作成功",
  "data": {
    "id": 45,
    "from_member": 5,
    "article": 100,
    "tenant": 1,
    "created_at": "2024-01-20T10:30:00Z",
    "ip_address": "192.168.1.100",
    "user_agent": "Mozilla/5.0..."
  }
}
```

### 3. 检查点赞状态

在显示文章详情时，检查是否已点赞：

```bash
GET /api/v1/interactions/article-likes/check/100/
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
X-Tenant-ID: 1
```

**响应示例：**
```json
{
  "success": true,
  "data": {
    "is_liked": true,
    "like_id": 45,
    "created_at": "2024-01-20T10:30:00Z"
  }
}
```

### 4. 取消点赞

```bash
DELETE /api/v1/interactions/article-likes/by-article/100/
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
X-Tenant-ID: 1
```

**响应示例：**
```json
{
  "success": true,
  "code": 2000,
  "message": "已取消点赞"
}
```

## 🌐 API 端点总览

### 基础 URL
```
生产环境: https://api.yourdomain.com
开发环境: http://localhost:8000
```

### 所有端点

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/v1/interactions/article-likes/` | 获取我点赞的文章列表 |
| POST | `/api/v1/interactions/article-likes/` | 点赞文章 |
| DELETE | `/api/v1/interactions/article-likes/{id}/` | 取消点赞（通过记录ID） |
| DELETE | `/api/v1/interactions/article-likes/by-article/{article_id}/` | 取消点赞（通过文章ID） |
| GET | `/api/v1/interactions/article-likes/check/{article_id}/` | 检查点赞状态 |
| GET | `/api/v1/interactions/article-likes/by-article/{article_id}/likers/` | 获取文章的点赞用户列表 |

## 💡 典型使用场景

### 场景 1: 文章详情页

```javascript
// 1. 页面加载时检查点赞状态
const checkLikeStatus = async (articleId) => {
  const response = await fetch(
    `/api/v1/interactions/article-likes/check/${articleId}/`,
    {
      headers: {
        'Authorization': `Bearer ${token}`,
        'X-Tenant-ID': tenantId
      }
    }
  );
  const data = await response.json();
  return data.data.is_liked;
};

// 2. 用户点击点赞/取消点赞按钮
const toggleLike = async (articleId, isLiked) => {
  if (isLiked) {
    // 取消点赞
    await fetch(
      `/api/v1/interactions/article-likes/by-article/${articleId}/`,
      {
        method: 'DELETE',
        headers: {
          'Authorization': `Bearer ${token}`,
          'X-Tenant-ID': tenantId
        }
      }
    );
  } else {
    // 点赞
    await fetch('/api/v1/interactions/article-likes/', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'X-Tenant-ID': tenantId,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ article: articleId })
    });
  }
};
```

### 场景 2: 我的点赞列表页

```javascript
// 获取我点赞的文章列表
const getMyLikedArticles = async (page = 1) => {
  const response = await fetch(
    `/api/v1/interactions/article-likes/?page=${page}`,
    {
      headers: {
        'Authorization': `Bearer ${token}`,
        'X-Tenant-ID': tenantId
      }
    }
  );
  const data = await response.json();
  return data.data.results;
};
```

### 场景 3: 文章点赞用户列表

```javascript
// 显示谁点赞了这篇文章
const getArticleLikers = async (articleId, page = 1) => {
  const response = await fetch(
    `/api/v1/interactions/article-likes/by-article/${articleId}/likers/?page=${page}`,
    {
      headers: {
        'Authorization': `Bearer ${token}`,
        'X-Tenant-ID': tenantId
      }
    }
  );
  const data = await response.json();
  return data.data.results;
};
```

## ⚠️ 重要注意事项

### 1. 用户类型检查
```javascript
// 前端应该检查当前用户是否为 Member 类型
if (user.user_type !== 'member') {
  // 隐藏或禁用点赞功能
  console.log('只有 Member 用户可以点赞');
}
```

### 2. 租户 ID 必填
```javascript
// 所有请求必须携带正确的租户 ID
headers: {
  'X-Tenant-ID': user.tenant_id  // 从登录响应中获取
}
```

### 3. Token 过期处理
```javascript
// Token 过期时应该刷新或重新登录
if (response.status === 401) {
  // 使用 refresh_token 刷新 access_token
  // 或者跳转到登录页
}
```

### 4. 防重复点赞
```javascript
// 点赞按钮应该有防抖处理
let isLiking = false;

const handleLike = async () => {
  if (isLiking) return;
  isLiking = true;
  
  try {
    await likeArticle();
  } finally {
    isLiking = false;
  }
};
```
