## 快速开始

### 1. 基本流程

```
1. 用户登录 → 获取Token
2. 使用Token访问文章API
3. 所有请求需要携带租户ID
```

### 2. 最小可用示例

```javascript
// 1. 登录获取Token
const loginResponse = await fetch('http://your-domain.com/api/v1/auth/login/', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Tenant-ID': '1'
  },
  body: JSON.stringify({
    username: 'your_username',
    password: 'your_password'
  })
});

const { data } = await loginResponse.json();
const token = data.token;

// 2. 获取文章列表
const articlesResponse = await fetch('http://your-domain.com/api/v1/cms/member/articles/', {
  headers: {
    'Authorization': `Bearer ${token}`,
    'X-Tenant-ID': '1'
  }
});

const articles = await articlesResponse.json();
console.log(articles.data.results);
```

## 认证机制

### 1. 登录接口

**接口地址**: `POST /api/v1/auth/login/`

**请求头**:
```
Content-Type: application/json
X-Tenant-ID: {租户ID}
```

**请求参数**:
```json
{
  "username": "string",    // 必填，用户名
  "password": "string"     // 必填，密码
}
```

**成功响应** (200):
```json
{
  "success": true,
  "code": 2000,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "username": "test_user",
      "email": "test@example.com",
      "nick_name": "测试用户",
      "avatar": "",
      "is_member": true,
      "tenant_id": 1,
      "tenant_name": "测试租户"
    }
  }
}
```

**错误响应** (400/401):
```json
{
  "success": false,
  "code": 4001,
  "message": "用户名或密码错误",
  "data": null,
  "error_code": "AUTH_INVALID_CREDENTIALS"
}
```

### 2. Token使用

获取Token后，所有后续请求都需要在请求头中携带：

```
Authorization: Bearer {token}
```

**Token有效期**: 
- Access Token: 30天
- Refresh Token: 60天

**Token刷新**: 
- 接口: `POST /api/v1/auth/refresh/`
- 使用refresh_token获取新的access_token

## 通用规范

### 1. 请求头规范

**所有请求必须携带的请求头**:

```javascript
{
  'Content-Type': 'application/json',           // 内容类型
  'Authorization': 'Bearer {token}',            // 认证Token
  'X-Tenant-ID': '{tenant_id}'                  // 租户ID（必须）
}
```

**注意事项**:
- `X-Tenant-ID`必须是**数字字符串**，不能是`tenant_1`这种格式
- 正确示例: `'X-Tenant-ID': '1'` 或 `'X-Tenant-ID': '2'`
- 错误示例: ❌ `'X-Tenant-ID': 'tenant_1'`

### 2. 响应格式规范

所有API响应遵循统一格式：

**成功响应**:
```json
{
  "success": true,
  "code": 2000,              // 业务状态码
  "message": "操作成功",
  "data": {                  // 实际数据
    // ... 具体数据
  }
}
```

**错误响应**:
```json
{
  "success": false,
  "code": 4000,              // 业务状态码
  "message": "错误描述",
  "data": null,
  "error_code": "ERROR_CODE" // 错误码
}
```

### 3. HTTP状态码

| 状态码 | 说明 | 场景 |
|--------|------|------|
| 200 | 成功 | GET/PATCH/PUT请求成功 |
| 201 | 创建成功 | POST创建资源成功 |
| 204 | 无内容 | DELETE删除成功 |
| 400 | 请求错误 | 参数错误、验证失败 |
| 401 | 未认证 | Token缺失或无效 |
| 403 | 权限不足 | 没有操作权限 |
| 404 | 资源不存在 | 请求的资源不存在 |
| 500 | 服务器错误 | 服务器内部错误 |

### 4. 业务状态码

| Code | 说明 |
|------|------|
| 2000 | 操作成功 |
| 4000 | 请求参数错误 |
| 4001 | 认证失败 |
| 4003 | 权限不足 |
| 4004 | 资源不存在 |
| 5000 | 服务器内部错误 |

## 错误处理

### 1. 常见错误码

| Error Code | HTTP | 说明 | 处理建议 |
|------------|------|------|----------|
| AUTH_INVALID_CREDENTIALS | 401 | 用户名或密码错误 | 提示用户重新输入 |
| AUTH_TOKEN_EXPIRED | 401 | Token已过期 | 使用refresh_token刷新 |
| AUTH_TOKEN_INVALID | 401 | Token无效 | 重新登录 |
| AUTH_PERMISSION_DENIED | 403 | 权限不足 | 提示用户无权限 |
| VALIDATION_ERROR | 400 | 参数验证失败 | 检查参数格式 |
| RESOURCE_NOT_FOUND | 404 | 资源不存在 | 提示资源不存在 |
| INTERNAL_SERVER_ERROR | 500 | 服务器错误 | 提示稍后重试 |
| TENANT_ID_REQUIRED | 400 | 缺少租户ID | 添加X-Tenant-ID头 |
| TENANT_ID_INVALID | 400 | 租户ID格式错误 | 使用数字格式 |

### 2. 错误处理示例

```javascript
async function apiRequest(url, options) {
  try {
    const response = await fetch(url, options);
    const result = await response.json();
    
    // 检查业务状态
    if (!result.success) {
      switch (result.error_code) {
        case 'AUTH_TOKEN_EXPIRED':
          // Token过期，尝试刷新
          await refreshToken();
          return apiRequest(url, options); // 重试
          
        case 'AUTH_TOKEN_INVALID':
          // Token无效，重新登录
          redirectToLogin();
          break;
          
        case 'AUTH_PERMISSION_DENIED':
          // 权限不足
          showError('您没有执行此操作的权限');
          break;
          
        case 'TENANT_ID_INVALID':
          // 租户ID格式错误
          console.error('租户ID必须是数字格式');
          break;
          
        default:
          showError(result.message);
      }
      throw new Error(result.message);
    }
    
    return result.data;
  } catch (error) {
    console.error('API请求失败:', error);
    throw error;
  }
}

// 使用示例
try {
  const articles = await apiRequest('/api/v1/cms/member/articles/', {
    headers: {
      'Authorization': `Bearer ${token}`,
      'X-Tenant-ID': '1'
    }
  });
  console.log('文章列表:', articles);
} catch (error) {
  // 错误已经处理
}
```

### 3. Token刷新处理

```javascript
let isRefreshing = false;
let refreshSubscribers = [];

function subscribeTokenRefresh(callback) {
  refreshSubscribers.push(callback);
}

function onTokenRefreshed(newToken) {
  refreshSubscribers.forEach(callback => callback(newToken));
  refreshSubscribers = [];
}

async function refreshToken() {
  if (isRefreshing) {
    return new Promise(resolve => {
      subscribeTokenRefresh(token => resolve(token));
    });
  }
  
  isRefreshing = true;
  
  try {
    const response = await fetch('/api/v1/auth/refresh/', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-Tenant-ID': getTenantId()
      },
      body: JSON.stringify({
        refresh_token: getRefreshToken()
      })
    });
    
    const result = await response.json();
    
    if (result.success) {
      const newToken = result.data.token;
      saveToken(newToken);
      onTokenRefreshed(newToken);
      return newToken;
    } else {
      // 刷新失败，重新登录
      redirectToLogin();
      throw new Error('Token刷新失败');
    }
  } finally {
    isRefreshing = false;
  }
}
```

## 数据类型说明

### 1. 文章状态 (status)

| 值 | 说明 | 可见性 |
|----|------|--------|
| draft | 草稿 | 仅作者可见 |
| pending | 待审核 | 仅作者和管理员可见 |
| published | 已发布 | 所有人可见 |

| 值 | 说明 |
|----|------|

### 3. 内容类型 (content_type)

| 值 | 说明 |
|----|------|
| markdown | Markdown格式 |

## 分页说明

列表接口支持分页查询。

**分页参数**:
- `page`: 页码，默认1
- `page_size`: 每页数量，默认20，最大100

**分页响应**:
```json
{
  "success": true,
  "data": {
    "count": 100,           // 总记录数
    "next": "http://...?page=2",     // 下一页URL
    "previous": null,       // 上一页URL
    "results": [            // 当前页数据
      // ...
    ]
  }
}
```

**分页示例**:
```javascript
// 获取第2页，每页10条
const response = await fetch(
  '/api/v1/cms/member/articles/?page=2&page_size=10',
  {
    headers: {
      'Authorization': `Bearer ${token}`,
      'X-Tenant-ID': '1'
    }
  }
);
```
