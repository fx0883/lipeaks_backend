## 🔑 核心概念

### 认证流程
```
登录 → 获取Token → 携带Token访问API → Token过期 → 刷新或重登录
```

### 文章状态流转
```
draft → published
  ↓         ↓
archived ← archived
```

### 租户隔离
所有请求必须携带`X-Tenant-ID`头，系统自动进行租户隔离验证。

---

## ⚠️ 重要注意事项

1. **租户ID格式**: 必须是数字字符串，如`"1"`，不能是`"tenant_1"`
2. **Token携带**: 所有API请求都需要在请求头中携带`Authorization: Bearer {token}`
3. **CORS配置**: 确保后端已配置正确的CORS策略
4. **错误处理**: 建议使用统一的错误处理机制
5. **数据验证**: 前端也应进行数据验证，不要完全依赖后端
