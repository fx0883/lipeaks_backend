## 问题1: 创建版本时提示"software字段必填"

### 错误信息

```json
{
  "success": false,
  "code": 4000,
  "message": "请求参数错误",
  "data": {
    "software": ["该字段是必填项。"]
  }
}
```

### 原因分析

创建版本的URL是嵌套路由：`POST /software/{software_id}/versions/`

**错误原因**: 前端在请求体中包含了`software`字段，但这个字段应该从URL自动获取。

### 解决方案

**❌ 错误做法**:
```json
{
  "software": 1,      // 不要传这个字段
  "version": "v2.2.0",
  "version_code": 220
}
```

**✅ 正确做法**:
```json
{
  "version": "v2.2.0",
  "version_code": 220
  // 不需要传software字段
}
```

**后端已自动处理**: 系统会从URL的`{software_id}`自动获取software。

## 问题2: release_date日期格式错误

### 错误信息

```json
{
  "success": false,
  "code": 4000,
  "message": "请求参数错误",
  "data": {
    "release_date": ["日期格式错误。请从这些格式中选择：YYYY-MM-DD。"]
  }
}
```

### 原因分析

前端传了空字符串`""`给`release_date`字段。

**用户请求**:
```json
{
  "version": "2",
  "version_code": 1,
  "release_date": "",        // ❌ 空字符串会报错
  "release_notes": "",       // ❌ 空字符串会报错
  "download_url": ""         // ❌ 空字符串会报错
}
```

### 解决方案

#### 方案1: 不传可选字段（推荐）

```json
{
  "version": "v2.0.0",
  "version_code": 200
  // 不传可选字段
}
```

#### 方案2: 传null

```json
{
  "version": "v2.0.0",
  "version_code": 200,
  "release_date": null,      // ✅ 正确
  "release_notes": null,     // ✅ 正确
  "download_url": null       // ✅ 正确
}
```

#### 方案3: 前端清理空字符串

```javascript
const cleanData = (data) => {
  const cleaned = { ...data }
  
  // 删除空字符串字段
  Object.keys(cleaned).forEach(key => {
    if (cleaned[key] === '') {
      delete cleaned[key]
    }
  })
  
  return cleaned
}

// 使用
const requestData = cleanData(formData)
await axios.post('/api/v1/feedbacks/software/3/versions/', requestData)
```

## 问题3: 403权限错误

### 错误信息

```json
{
  "success": false,
  "code": 4003,
  "message": "Permission denied.",
  "data": null
}
```

### 原因分析

**可能原因**:
1. JWT Token过期或无效
2. 用户不是租户管理员
3. Token中缺少`is_staff`字段

### 解决方案

#### 1. 检查Token

**浏览器控制台执行**:
```javascript
const token = localStorage.getItem('token')
if (token) {
  const payload = JSON.parse(atob(token.split('.')[1]))
  console.log('Token内容:', payload)
  console.log('is_staff存在:', 'is_staff' in payload)
  console.log('is_staff值:', payload.is_staff)
}
```

**预期结果**:
```javascript
{
  user_id: 2,
  username: "admin_jin",
  is_admin: true,
  is_super_admin: false,
  is_staff: true,        // ✅ 必须存在且为true
  model_type: "user"
}
```

#### 2. 重新登录

如果Token中缺少`is_staff`字段或为`false`:

**步骤**:
1. 退出登录
2. 重新登录
3. 获取新Token（包含is_staff=true）
4. 重试API

#### 3. 检查用户角色

**确认当前用户是租户管理员**:
- 超级管理员（is_super_admin=true）**不能**管理软件
- 只有租户管理员（is_admin=true, is_super_admin=false）可以

## 问题4: 响应数据双层嵌套

### 错误现象

```json
{
  "success": true,
  "code": 2000,
  "message": "操作成功",
  "data": {
    "success": true,  // ❌ 重复
    "data": [...]     // ❌ 嵌套
  }
}
```

### 原因分析

**已修复**: 这是之前版本的问题，现在已经修复。

### 当前正确格式

```json
{
  "success": true,
  "code": 2000,
  "message": "操作成功",
  "data": [...]  // ✅ 只有一层data
}
```

**如果仍看到嵌套**:
1. 清除浏览器缓存
2. 重启后端服务器
3. 确认使用最新的API地址

## 快速诊断指南

### 遇到错误时的检查步骤

#### 1. 检查HTTP状态码

| 状态码 | 可能原因 | 解决方案 |
|--------|---------|---------|
| 400 | 参数错误 | 检查请求参数格式 |
| 401 | 未认证 | 检查Token是否有效 |
| 403 | 权限不足 | 重新登录或检查角色 |
| 404 | 资源不存在 | 检查ID是否正确 |
| 500 | 服务器错误 | 联系后端开发者 |

#### 2. 检查错误消息

```javascript
if (error.response) {
  console.log('状态码:', error.response.status)
  console.log('错误消息:', error.response.data.message)
  console.log('详细错误:', error.response.data.data)
}
```

#### 3. 验证错误处理

```javascript
if (error.response?.status === 400) {
  const errors = error.response.data.data
  if (typeof errors === 'object') {
    // 显示每个字段的错误
    Object.keys(errors).forEach(field => {
      console.error(`${field}: ${errors[field][0]}`)
      ElMessage.error(`${field}: ${errors[field][0]}`)
    })
  }
}
```

## 前端最佳实践

### 1. 统一的错误处理

```javascript
// utils/errorHandler.js
export const handleApiError = (error) => {
  if (!error.response) {
    ElMessage.error('网络错误，请检查网络连接')
    return
  }
  
  const { status, data } = error.response
  
  switch (status) {
    case 400:
      // 验证错误
      if (data.data && typeof data.data === 'object') {
        Object.keys(data.data).forEach(field => {
          ElMessage.error(`${field}: ${data.data[field][0]}`)
        })
      } else {
        ElMessage.error(data.message || '请求参数错误')
      }
      break
    case 401:
      ElMessage.error('登录已过期，请重新登录')
      // 跳转到登录页
      router.push('/login')
      break
    case 403:
      ElMessage.error('权限不足')
      break
    case 404:
      ElMessage.error('资源不存在')
      break
    case 500:
      ElMessage.error('服务器错误，请稍后重试')
      break
    default:
      ElMessage.error(data.message || '操作失败')
  }
}

// 使用
try {
  const response = await axios.post('/api/v1/feedbacks/software/1/versions/', data)
  // 处理成功...
} catch (error) {
  handleApiError(error)
}
```

### 2. 数据清理工具函数

```javascript
// utils/dataClean.js
export const cleanEmptyFields = (data) => {
  const cleaned = { ...data }
  
  Object.keys(cleaned).forEach(key => {
    // 删除空字符串
    if (cleaned[key] === '') {
      delete cleaned[key]
    }
    // 删除undefined
    if (cleaned[key] === undefined) {
      delete cleaned[key]
    }
  })
  
  return cleaned
}

// 使用
const requestData = cleanEmptyFields(formData)
await axios.post('/api/v1/feedbacks/software/1/versions/', requestData)
```

### 3. Token自动刷新

```javascript
// api/client.js
import axios from 'axios'

const client = axios.create({
  baseURL: '/api/v1/feedbacks'
})

// 响应拦截器
client.interceptors.response.use(
  response => response,
  async error => {
    if (error.response?.status === 401) {
      const refreshToken = localStorage.getItem('refresh_token')
      
      if (refreshToken) {
        try {
          // 刷新Token
          const response = await axios.post('/api/v1/auth/refresh/', {
            refresh: refreshToken
          })
          
          // 保存新Token
          const newToken = response.data.access
          localStorage.setItem('token', newToken)
          
          // 重试原请求
          error.config.headers.Authorization = `Bearer ${newToken}`
          return axios(error.config)
        } catch (refreshError) {
          // 刷新失败，跳转登录
          window.location.href = '/login'
        }
      } else {
        window.location.href = '/login'
      }
    }
    
    return Promise.reject(error)
  }
)
```
