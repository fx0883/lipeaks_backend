## 发现并修复的问题

### 1. Member用户权限问题

**问题描述**：  
Member用户无法创建文章，提示"You do not have permission to create articles"

**根本原因**：  
`common/utils/user_permissions.py`中的`can_create_content`函数只允许Admin用户创建内容，Member被拒绝。

**修复方案**：  
```python
# 修改前
def can_create_content(user):
    return is_admin(user)

# 修改后
def can_create_content(user):
    return is_member(user) or is_admin(user)
```

同时修复了`can_edit_content`和`can_delete_content`函数，允许Member编辑和删除自己的内容。

**影响范围**：
- Member用户现在可以创建、编辑、删除自己的文章
- Member用户可以发布自己的文章

---

### 2. 文章统计API返回500错误

**问题描述**：  
调用`GET /api/v1/cms/articles/{id}/statistics/`返回500内部服务器错误

**根本原因**：  
代码中使用了不存在的`check_date`字段，AccessLog模型中没有这个字段。

**错误代码**：
```python
views_by_date = logs_query.values('check_date') \  # check_date不存在
                .annotate(count=Count('id')) \
                .order_by('check_date')
```

**修复方案**：  
使用`TruncDate`函数从`created_at`字段提取日期部分：
```python
from django.db.models.functions import TruncDate

views_by_date = logs_query.annotate(date=TruncDate('created_at')) \
                .values('date') \
                .annotate(count=Count('id')) \
                .order_by('date')
```

**影响范围**：
- 文章统计API现在可以正常返回时间序列数据
- 支持按天统计文章浏览量

---

### 3. 租户ID传递方式不一致

**问题描述**：  
测试中Admin用户使用`X-Tenant-ID` header导致大量API返回400错误"Tenant operation failed"

**根本原因**：  
系统设计中，不同用户类型传递租户ID的方式不同：
- **Admin用户**：使用查询参数`?tenant_id=3`
- **Member用户**：使用HTTP Header`X-Tenant-ID: 3`

**解决方案**：  
更新测试脚本和文档，明确说明两种用户类型的租户ID传递规则。

**相关代码位置**：  
`common/viewsets.py`中的`TenantModelViewSet`类

---

### 4. 分类创建需要translations字段

**问题描述**：  
创建分类时返回400错误："translations字段是必填项"

**根本原因**：  
分类模型使用了django-parler支持多语言，创建时必须提供translations字段。

**正确的请求格式**：
```json
{
  "slug": "test-category",
  "translations": {
    "zh-hans": {
      "name": "测试分类",
      "description": "描述"
    }
  }
}
```

**影响范围**：
- 所有分类的创建和更新操作都需要提供translations字段
- 文档中已明确说明此要求

## 关键发现

### 1. 双用户类型支持

系统设计支持两种用户类型，具有不同的权限和访问方式：

**Admin用户**：
- 租户管理员角色
- 可以管理本租户所有资源
- 使用查询参数传递租户ID：`?tenant_id=3`
- Token中包含`is_admin: true`

**Member用户**：
- 普通会员角色
- 只能管理自己创建的资源
- 使用HTTP Header传递租户ID：`X-Tenant-ID: 3`
- Token中包含`model_type: "member"`

### 2. 文章作者双外键设计

文章模型支持两种作者类型：
```python
class Article(BaseModel):
    user = models.ForeignKey(User, ...)      # Admin作者
    member = models.ForeignKey(Member, ...)  # Member作者
```

约束：`user`和`member`有且仅有一个非空。

### 3. 多语言支持

分类模型使用django-parler支持多语言：
- 可翻译字段：name, description, seo_title, seo_description
- 非翻译字段：slug, parent, is_active等

### 4. 软删除机制

文章删除默认为软删除（将状态改为archived），除非明确指定`force=true`进行真删除。

## API规范总结

### 租户ID传递规则

| 用户类型 | 传递方式 | 示例 |
|----------|----------|------|
| Admin | 查询参数 | `?tenant_id=3` |
| Member | HTTP Header | `X-Tenant-ID: 3` |
| Super Admin | 查询参数（可选） | `?tenant_id=3` |

### 认证方式

所有需要认证的API都使用Bearer Token：
```
Authorization: Bearer {TOKEN}
```

### 响应格式

统一的成功响应格式：
```json
{
  "success": true,
  "code": 2000,
  "message": "操作成功",
  "data": { ... }
}
```

统一的错误响应格式：
```json
{
  "success": false,
  "code": 4000,
  "message": "错误描述",
  "data": null,
  "error_code": "ERROR_CODE"
}
```

### 状态码规范

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 201 | 创建成功 |
| 204 | 删除成功（无内容） |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 前端集成建议

### 1. Token管理

```javascript
// 存储token
localStorage.setItem('accessToken', token);
localStorage.setItem('userType', 'member'); // or 'admin'
localStorage.setItem('tenantId', '3');

// 获取token
const token = localStorage.getItem('accessToken');
const userType = localStorage.getItem('userType');
const tenantId = localStorage.getItem('tenantId');
```

### 2. API请求封装

```javascript
async function apiRequest(endpoint, options = {}) {
  const token = localStorage.getItem('accessToken');
  const userType = localStorage.getItem('userType');
  const tenantId = localStorage.getItem('tenantId');
  
  const headers = {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`,
    ...options.headers
  };
  
  // Member用户使用Header，Admin用户使用查询参数
  let url = endpoint;
  if (userType === 'member') {
    headers['X-Tenant-ID'] = tenantId;
  } else if (userType === 'admin') {
    url += (url.includes('?') ? '&' : '?') + `tenant_id=${tenantId}`;
  }
  
  const response = await fetch(url, {
    ...options,
    headers
  });
  
  return response.json();
}
```

### 3. 使用示例

```javascript
// 获取文章列表
const articles = await apiRequest('/api/v1/cms/articles/');

// 创建文章
const newArticle = await apiRequest('/api/v1/cms/articles/', {
  method: 'POST',
  body: JSON.stringify({
    title: '新文章',
    content: '内容',
    content_type: 'markdown'
  })
});

// Member获取自己的文章
const myArticles = await apiRequest('/api/v1/cms/member/articles/');
```
