## 使用说明

1. 按照顺序阅读文档，从部署概述开始
2. 根据您的需求和环境调整命令和配置
3. 完成每个步骤后，确保验证结果
4. 遇到问题时，参考常见问题排查文档

## 注意事项

- 在执行任何命令前，确保已经备份重要数据
- 根据您的cPanel主机提供商的具体配置，某些步骤可能需要调整
- 某些高级功能（如Memcached、Redis）可能不是所有cPanel主机都支持
