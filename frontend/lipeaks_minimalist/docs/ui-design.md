# 21天自律打卡 APP UI设计文档

> 本文档定义了21天自律打卡APP的完整UI设计规范

---

## 一、设计系统

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **极简至上** | 去除冗余元素，聚焦核心功能 |
| **色彩驱动** | 21种主题色贯穿设计，强化视觉区分 |
| **即时反馈** | 每个操作都有清晰的视觉/触觉反馈 |
| **一致性** | 组件风格、间距、动效保持统一 |

### 1.3 字体规范

| 用途 | 字体 | 字号 | 字重 |
|------|------|------|------|
| 大标题 H1 | Noto Sans SC | 28px | Bold (700) |
| 标题 H2 | Noto Sans SC | 22px | SemiBold (600) |
| 小标题 H3 | Noto Sans SC | 18px | Medium (500) |
| 正文 Body | Noto Sans SC | 16px | Regular (400) |
| 辅助文本 Caption | Noto Sans SC | 14px | Regular (400) |
| 标签 Label | Noto Sans SC | 12px | Medium (500) |

**行高**: 1.5 倍字号

---

### 1.4 间距系统

基于 4px 网格:

| Token | 值 | 用途 |
|-------|------|------|
| `spacing-xs` | 4px | 紧凑元素间距 |
| `spacing-sm` | 8px | 小间距 |
| `spacing-md` | 16px | 标准间距 |
| `spacing-lg` | 24px | 大间距 |
| `spacing-xl` | 32px | 区块间距 |
| `spacing-2xl` | 48px | 页面边距 |

---

### 1.5 圆角规范

| Token | 值 | 用途 |
|-------|------|------|
| `radius-sm` | 8px | 小按钮、标签 |
| `radius-md` | 12px | 卡片、输入框 |
| `radius-lg` | 16px | 弹窗、大卡片 |
| `radius-full` | 9999px | 圆形按钮、头像 |

---

### 1.6 阴影规范

| Token | 值 | 用途 |
|-------|------|------|
| `shadow-sm` | `0 1px 2px rgba(0,0,0,0.05)` | 轻微浮起 |
| `shadow-md` | `0 4px 6px rgba(0,0,0,0.1)` | 卡片悬浮 |
| `shadow-lg` | `0 10px 15px rgba(0,0,0,0.1)` | 弹窗、浮层 |

## 二、组件库

### 2.1 按钮 (Button)

#### 主按钮
```
┌─────────────────────────┐
│     确认并开始打卡       │  
└─────────────────────────┘
背景: 主题色渐变
文字: 白色, 16px, Bold
圆角: 12px
高度: 48px
```

#### 次级按钮
```
┌─────────────────────────┐
│       取消              │
└─────────────────────────┘
背景: 透明
边框: 1px 主题色
文字: 主题色, 16px
```

#### 文本按钮
```
跳过 →
文字: 灰色, 14px
无背景无边框
```

#### 按钮状态

| 状态 | 样式变化 |
|------|----------|
| 默认 | 正常显示 |
| 悬停 | 透明度 0.9 + 轻微放大 1.02 |
| 按下 | 透明度 0.8 + 缩小 0.98 |
| 禁用 | 透明度 0.5 + 不可点击 |

## 四、动效规范

### 4.1 过渡动画

| 动画类型 | 时长 | 缓动函数 |
|----------|------|----------|
| 页面切换 | 300ms | ease-out |
| 弹窗出现 | 250ms | ease-out |
| 弹窗消失 | 200ms | ease-in |
| 卡片点击 | 150ms | ease |
| 按钮反馈 | 100ms | ease |

### 4.2 微交互

| 交互 | 效果 |
|------|------|
| 卡片选中 | 缩放 1.02 + 边框出现 |
| 按钮按下 | 缩放 0.98 + 透明度 0.8 |
| 打卡成功 | Confetti 彩带动画 🎉 |
| 进度更新 | 进度条平滑填充动画 |
| 数字变化 | 计数器滚动动画 |

### 4.3 加载状态

| 场景 | 效果 |
|------|------|
| 页面加载 | 骨架屏 Skeleton |
| 数据提交 | 按钮内 Loading Spinner |
| 图片加载 | 模糊渐变占位图 |

## 五、响应式设计

### 5.1 断点

| 设备 | 断点 | 布局 |
|------|------|------|
| 手机竖屏 | < 480px | 单列/双列 |
| 手机横屏 | 480-768px | 三列 |
| 平板 | 768-1024px | 四列 |
| 桌面 | > 1024px | 最大宽度 480px 居中 |

### 5.2 安全区域

- 顶部: `env(safe-area-inset-top)`
- 底部: `env(safe-area-inset-bottom) + 16px`
- 左右: `16px`

## 六、无障碍设计

### 6.1 颜色对比度

- 正文与背景对比度 ≥ 4.5:1
- 大文字与背景对比度 ≥ 3:1
- 所有主题色都经过对比度验证

### 6.2 触摸目标

- 最小点击区域: 44px × 44px
- 按钮间距: ≥ 8px

### 6.3 屏幕阅读器

- 所有图标提供 aria-label
- 表单字段关联 label
- 状态变化提供 aria-live 通知
