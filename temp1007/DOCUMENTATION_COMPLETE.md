## 🔧 API端点总结

### Web前端API（Member调用）

```
基础路径: /api/v1/licenses/member/

GET  /available-products/    # 获取可申请产品列表
POST /apply/                 # 申请试用许可证  
GET  /my-licenses/           # 查看我的许可证
```

### 客户端软件API（软件调用）

```
基础路径: /api/v1/licenses/

POST /activate/     # 激活许可证
POST /verify/       # 验证激活状态
POST /heartbeat/    # 发送心跳
POST /unbind/       # 解绑许可证
GET  /info/{key}/   # 获取许可证信息
GET  /status/       # 服务器状态
```

## 📌 关键要点提醒

### ⚠️ 前端开发人员必须注意

1. **许可证密钥保护**
   - 完整密钥仅在申请成功时返回一次
   - 必须提示用户保存或复制
   - 建议提供多种保存方式（复制、下载、邮件）

2. **频率限制处理**
   - 申请API：5次/天
   - 需要友好的错误提示
   - 建议显示倒计时

3. **业务规则提示**
   - 提前检查是否已申请
   - 提前检查试用配额
   - 清晰的错误提示和引导

4. **用户体验**
   - 过期提醒要醒目
   - 激活指南要清晰
   - 错误处理要友好

### ⚠️ 客户端开发人员必须注意

1. **硬件信息收集**
   - 使用可靠的硬件ID库
   - 确保唯一性和稳定性

2. **激活码保存**
   - 安全存储activation_code
   - 用于后续验证和心跳

3. **心跳机制**
   - 定期发送（建议5分钟）
   - 错误重试机制
   - 离线处理

4. **过期检查**
   - 启动时验证
   - 定期检查
   - 过期后禁用功能
